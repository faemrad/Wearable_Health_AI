# Wearable Health AI
A program for processing wearable data and extracting key features such as heart rate and activity prediction.

Main data files used for testing and training:

1. PPG-Sport: A Dataset for Reliable Heart Rate Monitoring from Wrist PPG Under Dynamic Sports Conditions
   a. Paper link: https://www.repository.cam.ac.uk/items/9274ab4a-322f-4bd7-a9f1-0fa347cacad4
   b. Dataset link: https://github.com/LaserHu/PPG-Sport

2. Human Activity Recognition
   a. Paper link:
   b. Dataset link: https://github.com/netd-tud/human-activity-Recognition

Download PPG-SPort into data files under ./data/PPG-Sport
Run PPGSportPreparation(add_time=True) in main to setup files for training
